# Actividad 1 - Programación Web (Tema 2)

Este repositorio reúne los 18 ejercicios prácticos desarrollados en clase para consolidar los fundamentos del desarrollo web del lado del cliente: maquetación semántica con HTML5, diseño y estilos con CSS3, y manipulación del DOM e interactividad con JavaScript.

---
## Descripcion de los ejercicios

* **Ejercicio 1 al 10:** Estructura básica HTML5, etiquetas de texto, listas, tablas y vinculación inicial de estilos/scripts.
* **Ejercicio 11 al 15:** Formularios, validaciones en frontend, manejo de eventos de usuario e integración CSS avanzada.
* **Ejercicio 16 al 18:** Manipulación del DOM en tiempo real, creación y eliminación dinámica de elementos e interactividad completa.

##  Objetivos de Aprendizaje

* **HTML5:** Estructuración semántica, enlaces internos/externos, formularios, tablas y manejo de elementos multimedia.
* **CSS3:** Modelos de caja, selectores por clase e ID, tipografías y reglas de estilo aplicadas a componentes web.
* **JavaScript:** Fundamentos de sintaxis, variables, eventos, funciones y manipulación dinámica del DOM (árbol de elementos).
